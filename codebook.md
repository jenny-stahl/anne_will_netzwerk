# Codebuch für Anne Will Netzwerk 

Untersucht werden soll ein Netzwerk der Gäste von Anne Will und ihrer Parteizugehörigkeit. 

### Nodelist 
id = Initialen Vor- und Nachname, kleingeschrieben  
name = Voller Name der Person  
type:  
1 = Person  
2 = Organisation  
party = Parteizugehörigkeit  
sector = berufliches Spektrum der Person  
country = Land  

### Edgelist
from = Gast  
to = besuchte Show oder Parteimitgliedschaft  
relationship:  
1 = Gast  
2 = Mitgliedschaft
